# חיבור למאנדיי

## מה נוצר במאנדיי
- **לוח סיכומי פגישות:** פריט לכל פגישה או שיחה. הסיכום עצמו נכתב כעדכון (Update) על הפריט. עמודות אופציונליות: תאריך, משתתפים, החלטות.
- **לוח משימות:** פריט לכל משימה פתוחה, עם תאריך. אם יש עמודת Connect boards ללוח הסיכומים, המשימה מקושרת לסיכום שממנו היא באה.

## הגדרה (קלוד מוביל)
1. **שימוש בלוחות קיימים או יצירת לוחות חדשים:** קלוד שואל. אם יש כבר לוח משימות, עדיף להשתמש בו.
2. **מפתח API:** במאנדיי: תמונת הפרופיל ← **Developers** ← **My access tokens** ← Show ← Copy.
   שומרים אותו רק דרך החלון המאובטח (המקלדת באנגלית!):
   `python recordings-kit/scripts/secrets_store.py set MONDAY_API_TOKEN`
   **לא מדביקים את המפתח בצ'אט.**
3. **מזהים:** קלוד קורא את מבנה הלוחות דרך ה-API (או דרך מחבר מאנדיי, אם הוא מחובר), ומכניס ל-`config.json` את המזהים של הלוחות, הקבוצות והעמודות.
   כל יצירה של לוח, עמודה או קבוצה רק באישור.
4. **בדיקה:** מריצים סיכום אחד (`push_to_monday.py <json> <key>`) ובודקים יחד שהוא נראה טוב.

## בלי מאנדיי
`"summaries": "files"` בקונפיג. כל סיכום נשמר כקובץ Markdown בתיקייה לפי נושא, וכל המשימות נאספות
לקובץ אחד, `משימות פתוחות.md`, עם תיבת סימון וקישור לסיכום. אם התיקייה בגוגל דרייב, הכל נגיש גם מהטלפון.
חלופות שקלוד יכול להתאים לפי מה שכבר יש לך: Notion, Google Tasks, או Google Docs במקום Markdown.
