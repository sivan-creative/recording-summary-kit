# האזנה שקטה לסרטונים ושיעורים מהרשת

בשביל הקלטות שאי אפשר להוריד: הקלטת זום מוגנת בסיסמה, שיעורים בפלטפורמת קורסים, וובינר מוקלט.
זום וחלק מהפלטפורמות חוסמים הורדה במכוון, גם למשתמש מחובר. לכן אין קיצור דרך: מנגנים את הסרטון
(במהירות 1.5) ומקליטים את הצליל תוך כדי. קלוד עושה את זה לבד בדפדפן אוטומטי, גם בלילה.

## איך זה שקט
בזמן ההקלטה, ווינדוס שולח את **כל** צלילי המחשב לכבל וירטואלי במקום לרמקולים. כך אף אחד לא שומע,
ו-ffmpeg מקליט את הכבל. בסוף ההקלטה הרמקולים חוזרים, גם אם הייתה שגיאה. לכן עדיף להריץ כשלא
משתמשים במחשב, כי בזמן הזה גם צלילים אחרים לא יישמעו.

## התקנה (פעם אחת)
1. **VB-CABLE** (חינמי, vb-audio.com/Cable): להוריד את ה-ZIP, לחלץ, קליק ימני על
   `VBCABLE_Setup_x64.exe` ← **Run as administrator** ← Install Driver ← **להפעיל מחדש את המחשב**.
   את זה קלוד לא יכול לעשות לבד, כי נדרש אישור מנהל (UAC) על המסך.
2. **AudioDeviceCmdlets** (מודול PowerShell שמחליף את התקן השמע): קלוד מתקין לבד:
   `Install-Module AudioDeviceCmdlets -Scope CurrentUser -Force`
3. **Playwright MCP** (הדפדפן שקלוד מפעיל): צריך Node.js (`winget install OpenJS.NodeJS.LTS`), ואז:
   `claude mcp add playwright -- npx @playwright/mcp@latest`. אחר כך צריך להפעיל מחדש את Claude Code.
4. **בדיקה:** קלוד מריץ הקלטה של 10 שניות בזמן שמתנגן צליל בדיקה. אחר כך הוא בודק שהקובץ לא שקט
   (`volumedetect` לא מחזיר `-inf`), ושואל אם שמעת משהו. אם שמעת, הניתוב לא נכון.

## למי שכבר יש Voicemeeter
אפשר להשתמש בו במקום VB-CABLE (ככה זה נבדק במקור, ספטמבר 2026):
- הפרמטרים לסקריפט: `-PlaybackDevice 'Voicemeeter Input' -CaptureDevice 'Voicemeeter Out B1 (VB-Audio Voicemeeter VAIO)'`.
- **תוכנת Voicemeeter חייבת לרוץ ברקע.** אם היא סגורה, ההתקן קיים אבל מקליט שקט מוחלט. התוצאה היא
  תמלול שכולו "תודה רבה" חוזר, מתחילתו ועד סופו.
- כדי שיהיה שקט: ברצועה "Voicemeeter Input" לכבות את **A1** ולהשאיר את **B1** דלוק.
- אם אחרי ההתקנה שומעים אותך חלש בזום, כנראה Voicemeeter שינה גם את ברירת המחדל של המיקרופון. צריך
  להחזיר בהגדרות הצליל של ווינדוס ובזום.

## לקחים מהשימוש
- **לא לתמלל תוך כדי הקלטה.** תמלול בזמן אמת קרס בהקלטות ארוכות. מקליטים לקובץ ומתמללים אחרי.
- **מהירות 1.5** מאזנת בין זמן לדיוק. ב-2 התמלול בעברית ובמונחים מקצועיים נפגע.
- **הסוף:** `currentTime` מתאפס ל-0 ו-`paused` הופך ל-true, לפעמים עם `ERR_CONNECTION_RESET`. זה סיום רגיל.
  אם זה קורה באמצע הסרטון, זו תקלת רשת. לרוב הנגן מתאושש לבד.
- **סרטון בתוך iframe או Shadow DOM:** מחפשים את ה-`<video>` בתוך המסגרת, עם חיפוש שעובר גם על shadowRoot.
