# פורמט קובץ הסיכומים (JSON)

אותו פורמט משמש גם את `push_to_monday.py` וגם את `save_summary_files.py`. הקובץ הוא רשימה, ואפשר לשים בו כמה סיכומים.

```json
[
  {
    "key": "dana-2026-10-08",
    "name": "דנה כהן - סדנת צוות - 8.10.26",
    "topic": "עבודה",
    "date": "2026-10-08",
    "source": "שיחת טלפון",
    "participants": "דנה כהן, אני",
    "purpose": "פסקה אחת: על מה השיחה ולמה היא התקיימה.",
    "bullets": ["נקודה עיקרית", "נקודה נוספת"],
    "decisions": "מה הוחלט, במשפט או שניים.",
    "tasks": [{"name": "לשלוח לדנה הצעת מחיר", "date": "2026-10-12"}],
    "transcript": "G:/My Drive/תמלולים/עבודה/דנה כהן - סדנת צוות - 8.10.26.txt"
  }
]
```

- `key`: מזהה ייחודי. סיכום שכבר נשלח עם אותו key מדולג בהרצה חוזרת.
- `source`: "שיחת טלפון" / "פגישת זום" / "פגישה פרונטלית" / "שיעור מוקלט".
- `tasks`: רק פעולות פתוחות של בעל/ת החשבון. לא כל דבר שנאמר בשיחה הוא משימה.
- תאריכים בפורמט `YYYY-MM-DD`.
