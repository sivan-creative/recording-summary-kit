# ערכת הקלטות ותמלול בעברית, עם קלוד קוד

מחליפה שירותי הקלטה וסיכום בתשלום (כמו Timeless או Otter) בתהליך שרץ על המחשב שלך, בחינם:

- **שיחות טלפון והקלטות רשמקול** עולות לבד מהטלפון למחשב.
- **פגישות זום** מוקלטות במחשב, עם קובץ נפרד לכל משתתף, וכך ברור מי אמר מה.
- **שיעורים וסרטונים מהרשת** שאי אפשר להוריד: קלוד מנגן אותם בשקט, למשל בלילה, ומתמלל.
- **תמלול בעברית** במחשב שלך, עם המודל של ivrit.ai. ההקלטות לא נשלחות לשום שירות תמלול.
- **סיכום ומשימות** נכנסים למאנדיי, או לקבצים מסודרים בגוגל דרייב.
- **כל לילה** ההקלטות של היום מעובדות, ובבוקר הסיכומים כבר מחכים.

## מה צריך
- מחשב Windows עם [Claude Code](https://claude.com/claude-code) מותקן.
- אנדרואיד (נבדק על סמסונג) או אייפון. באייפון ההעברה למחשב פחות אוטומטית.
- אם במחשב יש כרטיס מסך NVIDIA, התמלול מהיר מאוד. גם בלעדיו זה עובד, רק לאט יותר.
- כחצי שעה עד שעה להתקנה הראשונה. רוב הזמן קלוד עובד לבד.

## איך מתחילים
פותחים את קלוד קוד ומדביקים:

> תוריד את הערכה מ-https://github.com/sivan-creative/recording-summary-kit ותתקין לי אותה לפי START-HERE.md. תדריך אותי צעד אחרי צעד.

קלוד יבדוק מה כבר מותקן אצלך ויתקין לבד את מה שהוא יכול. בדברים שצריך לעשות ביד, כמו הגדרות בטלפון ובזום,
הוא ידריך אותך צעד אחד בכל פעם. אפשר לשלוח לו צילום מסך בכל שלב.

## חשוב לדעת
- **פרטיות:** התמלולים כוללים גם שיחות אישיות. הם נשמרים רק בתיקייה שלך ולא משותפים עם אף אחד.
- **הקלטה מותרת:** בישראל מותר להקליט שיחה שאת/ה משתתף/ת בה. מקובל לעדכן את הצד השני, בעיקר מול לקוחות.
- **מה אין:** אין בוט שנכנס לבד לפגישות. בזום מגדירים הקלטה אוטומטית או לוחצים Record. בגוגל מיט ובטימס אין קובץ נפרד לכל משתתף.
- **לפני שמבטלים שירות בתשלום:** לייצא ממנו את ההיסטוריה. קלוד יעזור.

## מה יש בתיקייה
| קובץ | מה הוא עושה |
|---|---|
| `START-HERE.md` | תוכנית ההתקנה שקלוד עובד לפיה |
| `scripts/check_setup.py` | בודק מה מותקן ומה חסר |
| `scripts/transcribe.py` | תמלול הקלטות מהטלפון או קובץ בודד |
| `scripts/diarize.py` | מי אמר מה, בהקלטה שבה כולם על ערוץ אחד |
| `scripts/process_zoom.py` | תמלול פגישות זום לפי משתתף, ותיוק |
| `scripts/file_recording.py` | שם קריא ותיקייה לפי נושא |
| `scripts/capture_online.ps1` | הקלטה שקטה של סרטון מהרשת |
| `scripts/push_to_monday.py` / `save_summary_files.py` | סיכומים ומשימות למאנדיי או לקבצים |
| `scripts/secrets_store.py` | שמירת מפתחות בכספת של ווינדוס, לא בקבצים |
| `skill/recordings/SKILL.md` | הסקיל שקלוד מפעיל ביום-יום ("תסכם את ההקלטות החדשות") |
| `nightly/` | הריצה הלילית |
| `docs/` | מדריכים: טלפון, זום, שיעורים מהרשת, מאנדיי |

נבנה ונבדק באוקטובר 2026 על Windows 11, Galaxy S26 ו-Zoom Workplace.
